# Future Improvements

- better state and fallback handling
- richer analytics and drop-off tracking
- CRM integration
- improved lead scoring
- human-review queue
- more robust booking synchronization
- additional channels such as email or WhatsApp
- automated quality evaluation of conversations
- selectively introduce custom code where no-code becomes limiting

Custom code should be introduced because of a concrete need — scale, reliability, maintainability, latency, cost or unavailable functionality — not simply because code is more impressive.
