# Qualification Logic

The system is designed to collect only information that can affect the next action.

Depending on the scenario, qualification may include:

- current challenge
- desired outcome
- current process
- urgency
- readiness
- previous action or response
- booking state

Not every conversation needs every field.

## Principle

A qualification question should have a business reason.

If an answer does not change personalization, routing or the next step, the question probably should not be asked.

## Possible outcomes

- continue the DM conversation
- send a useful resource
- move toward a demo or call
- mark/update lead status
- human follow-up
