# Conversation Design

## Core idea

Typical automation:

`Comment → automated DM → link`

This system instead aims for:

`Comment → relevant scenario → conversation → qualification → next action`

## Principles

- Keep messages short.
- Ask one main question at a time.
- Avoid asking for information already available.
- Do not rush to a booking link.
- Keep the conversation connected to the original CTA.
- Allow human follow-up when automation is no longer the best option.

The system is deliberately structured rather than fully free-form. Predictable flows are easier to test, debug and improve.
