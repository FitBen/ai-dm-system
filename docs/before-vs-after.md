# Before vs After

This is a design comparison, not measured conversion data.

| Typical CTA automation | This prototype |
|---|---|
| Comment triggers generic response | Trigger launches a relevant scenario |
| Link often appears immediately | Qualification can precede the CTA |
| Little structured context | Fields, tags and spreadsheet data |
| Minimal routing | Workflow state can drive next action |
| One-shot automation | Conversation can continue over multiple steps |
| Limited visibility | Google Sheets provides inspectable state |

No performance percentages are claimed without measured data.
