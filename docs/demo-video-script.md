# 60-Second Demo Video Script

## 0–8 sec
Show the CTA Reel/comment.

**Voiceover:** “Most CTA automations treat a comment like a request for a link. I wanted the workflow to start a useful conversation instead.”

## 8–20 sec
Show the relevant ManyChat scenario.

**Voiceover:** “The trigger determines which scenario starts, so the flow already knows the context of the interaction.”

## 20–34 sec
Zoom through a few ManyChat branches.

**Voiceover:** “The conversation qualifies progressively and stores information as fields and states rather than forcing the prospect through a long form.”

## 34–46 sec
Show the Make scenario.

**Voiceover:** “Make receives and routes workflow data, connecting the conversation layer to the structured data layer.”

## 46–54 sec
Show Google Sheets.

**Voiceover:** “Google Sheets keeps lead state, qualification and booking information transparent and easy to inspect during prototyping.”

## 54–60 sec
Show the architecture diagram.

**Voiceover:** “The result is a no-code prototype designed to make the next step more relevant — not simply faster.”
