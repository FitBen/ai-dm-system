# Lessons Learned

## Workflow beats prompt cleverness
The structure of the conversation can matter more than making individual messages sound sophisticated.

## The trigger already contains context
Do not use AI to infer information the system already knows.

## No-code can be the correct prototype architecture
ManyChat, Make and Google Sheets allowed rapid iteration without spending time rebuilding commodity infrastructure.

## Every question has a cost
Qualification creates friction, so each question should justify itself.

## Booking is not the only valid outcome
A useful resource, continued conversation or human follow-up can be a better next step.

## Real users do not follow diagrams
People answer unpredictably, skip questions and reply later. The flow must be tested against real behavior.

## Prototype for learning
The first goal is not perfect architecture. It is to learn whether the workflow solves the intended business problem.
